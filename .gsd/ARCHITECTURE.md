## Data Flow

1. **Discovery:** User selects filters in `Home.jsx` or specialized chat pages.
2. **Signaling:** Client emits `video-find-random` to `server/server.js`.
3. **Matching:** Server finds a peer and emits `video-ready` with partner metadata and ICE servers.
4. **P2P Establishment:** Clients exchange SDP offers/answers and ICE candidates via the socket.
5. **Session:** Encrypted P2P connection established.
